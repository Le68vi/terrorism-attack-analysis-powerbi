Terrorism Attack Analysis Dashboard | Power BI
Project Overview

This project presents an interactive Power BI dashboard designed to explore historical terrorism-related incidents using a publicly available dataset sourced from GitHub.

The objective is to transform raw data into meaningful visualizations that help users explore temporal trends, geographic distributions, attack characteristics, target categories, and reported casualties.

Dashboard Pages
1. Overview

A summary of key metrics and major patterns in the dataset.

2. Time Analysis

Explores incident trends across different time periods.

3. Geographic Analysis

Examines the geographic distribution of recorded incidents.

4. Attack and Target Analysis

Explores attack methods and target categories.

5. Casualty Analysis

Examines reported fatalities and injuries, where available in the dataset.
